# SwiftBook

SwiftBook is an enterprise room management and scheduling application that we built as our final group project for a Software Engineering course.

## Overview

SwiftBook helps organizations manage buildings, rooms, users, and room bookings. We designed it as a client/server application with a Java desktop client and a PHP REST API.

## Features

- User login and registration
- User room booking and booking management
- Room details and availability
- Building and organization management
- Administrative dashboards for users, rooms, and buildings
- REST API clients for application resources

## Architecture

- **Client:** Java desktop application with Swing-based views
- **API:** PHP REST endpoints
- **Authentication:** PHP JWT integration
- **Resources:** Organizations, buildings, rooms, users, and bookings

## Project Structure

- `Client/` - Java desktop client
- `WebAPI/` - PHP REST API
- `Libraries/` - supporting project libraries
- `out/` - compiled application output

## Project Status

This repository contains our completed course project. It is preserved as a historical software engineering project and is no longer under active development.
